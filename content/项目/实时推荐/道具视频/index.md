# 道具视频模块

这组笔记把道具视频作为一个独立小模块，从素材与元数据入库，讲到实时位置查询、候选合并和网页播放。

- [接入流程](流程.md)：一张图串起素材入库、OCR/VLM 观测、SQLite 查询和 HTTP 播放。
- [源码实现](实现.md)：按 `clips-tool`、`SqliteClipRepository`、Drogon 路由和副屏播放器对照实现。

当前流程以代码和历史验收文档为依据，不据此推断 Linux 服务此刻加载的配置或数据库内容。服务器与 Windows 上本页涉及的关键查询、面板和媒体服务源码哈希已核对一致。
