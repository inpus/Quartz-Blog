# H.264视频解码

## 解码器初始化

### 查找解码器

```cpp
codec_ = const_cast<AVCodec*>(
    avcodec_find_decoder(codecParamer->codec_id)
);
```

> 根据输入视频流的 `codec_id` 查找对应的 H.264 解码器。

### 分配解码器上下文

```cpp
codecCtx_ = avcodec_alloc_context3(codec_);
```

> `AVCodecContext` 保存解码器运行所需的配置、输入参数以及解码状态。

### 写入视频流参数

```cpp
avcodec_parameters_to_context(codecCtx_, codecParamer);
```

> 将封装格式中获取的 `AVCodecParameters` 复制到解码器上下文中，包括：
>
> - 视频宽度和高度
> - 编码格式
> - 编码 profile
> - 编码 level
> - 码率等参数

### 打开解码器

```cpp
avcodec_open2(codecCtx_, codec_, nullptr);
```

> 初始化并打开 H.264 解码器。  
> 打开成功后，解码器才可以接收压缩数据包。

### 保存视频信息

```cpp
avContext_->video_width = codecCtx_->width;
avContext_->video_height = codecCtx_->height;
avContext_->video_fmt = AV_PIX_FMT_YUV420P;
```

> 将解码后的视频宽度、高度和输出像素格式保存到公共音视频上下文中。

---

## 初始化像素格式转换器

```cpp
videoConver_->Open(codecCtx_->width,
                   codecCtx_->height,
                   codecCtx_->pix_fmt,
                   codecCtx_->width,
                   codecCtx_->height,
                   AV_PIX_FMT_YUV420P);
```

> 使用 `VideoConverter` 将解码器输出的像素格式转换为 `YUV420P`。

### 创建 `SwsContext`

```cpp
swsContext_ = sws_getContext(
    in_width,
    in_height,
    in_format,
    out_width,
    out_height,
    out_format,
    SWS_BICUBIC,
    nullptr,
    nullptr,
    nullptr
);
```

> `sws_getContext` 来自 FFmpeg 的 `libswscale`，用于：
>
> - 像素格式转换
> - 视频尺寸缩放
> - 不同颜色格式之间的转换

> 当前转换方式使用 `SWS_BICUBIC`，即双三次缩放算法。

---

## 分配解码输出帧

```cpp
yuv_frame_ = AVFramePtr(
    av_frame_alloc(),
    [](AVFrame* ptr) {
        av_frame_free(&ptr);
    }
);
```

> `yuv_frame_` 用于接收 H.264 解码后的原始视频帧。

> 使用智能指针管理 `AVFrame`，当对象释放时自动调用 `av_frame_free`。

---

## 启动解码线程

```cpp
is_initial_ = true;
start();
```

> 初始化完成后启动 `QThread` 解码线程，实际解码逻辑在 `run()` 函数中执行。

---

# H.264视频解码流程

## 获取压缩数据包

```cpp
AVPacketPtr pkt = nullptr;

while (!quit_ && videoConver_) {
    if (!video_queue_.size()) {
        msleep(1);
        continue;
    }

    video_queue_.pop(pkt);
}
```

> `video_queue_` 保存待解码的 H.264 压缩数据包。

> 当队列为空时，解码线程休眠 `1 ms`，避免空转占用 CPU。

> 队列中有数据时，取出一个 `AVPacket` 进行解码。

---

## 发送压缩数据包

```cpp
if (avcodec_send_packet(codecCtx_, pkt.get())) {
    break;
}
```

> 将压缩的 H.264 数据包发送给解码器。

数据流向：

```text
AVPacket
   ↓
avcodec_send_packet()
   ↓
H.264解码器内部缓冲区
```

> `avcodec_send_packet` 只负责将数据送入解码器，不直接返回解码后的图像帧。

---

## 接收解码后的图像帧

```cpp
int ret = 0;

while (ret >= 0) {
    ret = avcodec_receive_frame(
        codecCtx_,
        yuv_frame_.get()
    );
}
```

> 一个压缩数据包可能解码出多个视频帧，因此需要循环调用 `avcodec_receive_frame`，直到当前数据包中的帧全部取出。

数据流向：

```text
H.264压缩数据
   ↓
avcodec_send_packet()
   ↓
avcodec_receive_frame()
   ↓
解码后的AVFrame
```

---

## 处理解码状态

```cpp
if (ret == AVERROR(EAGAIN) ||
    ret == AVERROR_EOF) {
    break;
}
else if (ret < 0) {
    break;
}
```

### `AVERROR(EAGAIN`

> 当前暂时没有可输出的视频帧，需要继续发送后续数据包。

### `AVERROR_EOF`

> 解码器已经到达输入数据末尾。

### 其他负数错误

> 表示解码过程中发生错误，当前代码会退出当前解码循环。

### 返回值大于等于 `0`

> 表示成功接收到一张解码后的图像帧，可以继续处理。

---

# 像素格式转换

## 调用转换器

```cpp
AVFramePtr outFrame = nullptr;

if (videoConver_->Convert(yuv_frame_, outFrame)) {
    if (outFrame) {
        // 添加到视频帧队列
    }
}
```

> 将解码器输出的 `yuv_frame_` 转换为 `YUV420P` 格式，并将结果保存到 `outFrame`。

---

## 分配输出帧缓存

```cpp
out_frame.reset(av_frame_alloc(), [](AVFrame* ptr) {
    av_frame_free(&ptr);
});

out_frame->width = width_;
out_frame->height = height_;
out_frame->format = format_;
```

> 为转换后的图像帧分配新的 `AVFrame`，并设置输出的：
>
> - 视频宽度
> - 视频高度
> - 像素格式

### 分配图像数据缓冲区

```cpp
av_frame_get_buffer(out_frame.get(), 0);
```

> 为输出帧分配 YUV 图像数据缓冲区。

对于 `YUV420P`，数据通常分为三个平面：

```text
data[0]：Y亮度分量
data[1]：U色度分量
data[2]：V色度分量
```

### 执行像素格式转换

```cpp
sws_scale(
    swsContext_,
    in_frame->data,
    in_frame->linesize,
    0,
    in_frame->height,
    out_frame->data,
    out_frame->linesize
);
```

> 使用 `libswscale` 将输入帧转换为输出格式。

同时复制时间戳：

```cpp
out_frame->pts = in_frame->pts;
out_frame->pkt_dts = in_frame->pkt_dts;
```

> 保留原始解码帧的时间戳，方便后续视频播放和音视频同步。

# 输出视频帧

```cpp
avContext_->video_queue_.push(outFrame);
```

> 将转换完成的 `YUV420P` 视频帧放入公共视频帧队列，供后续渲染线程读取。

完整数据流：

```text
H.264 AVPacket
        ↓
video_queue_
        ↓
avcodec_send_packet()
        ↓
avcodec_receive_frame()
        ↓
解码后的AVFrame
        ↓
VideoConverter::Convert()
        ↓
YUV420P AVFrame
        ↓
avContext_->video_queue_
        ↓
视频渲染器
```

# 关闭解码器

```cpp
void H264_Decoder::Close()
{
    quit_ = true;

    if (isRunning()) {
        quit();
        wait();
    }
}
```

> 设置退出标志后停止解码线程，并等待线程安全退出。

线程退出条件：

```cpp
while (!quit_ && videoConver_) {
    // 解码
}
```

> 当 `quit_` 设置为 `true` 后，解码循环结束。
