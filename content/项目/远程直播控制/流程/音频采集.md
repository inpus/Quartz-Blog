## 音频采集

### 说明

采样率 48000Hz 

WASAPI获取的音频帧代表48000hz其中的一组音频帧，如果是立体声（左右），那么1帧有2个采样点，所以有96000 个采样

### 初始化

#### Windows COM组件库初始化

```
CoInitialize(NULL);
```

> MMDeviceEnumerator、IAudioClient 全部属于 COM 对象。

- **所以COM的作用是什么**？

#### 创建设备枚举器

```c++
hr = CoCreateInstance(CLSID_MMDeviceEnumerator,NULL,CLSCTX_ALL,
                IID_IMMDeviceEnumerator,(void**)m_enumerator.GetAddressOf());
```

> `CLSID_MMDeviceEnumerator` : COM 类 ID，代表系统内置的音频设备枚举器组件。
>
> `NULL ` 不使用聚合（不需要外部 IUnknown）。
>
> `CLSCTX_ALL` 允许进程内 / 本地服务器创建组件，常规写法。
>
> `IID_IMMDeviceEnumerator` 想要获取的目标接口。
>
> `m_enumerator.GetAddressOf()`  `m_enumerator` 一般是 `WRL::ComPtr<IMMDeviceEnumerator>`；
>
> `GetAddressOf()` 返回 `IMMDeviceEnumerator**`，接收 COM 输出指针。

> 创建 **MMDeviceEnumerator（多媒体设备枚举器）**
>
> 作用：用来枚举电脑所有音频输入 / 输出声卡设备。
>
> **成员变量：**m_enumerator(void**)m_enumerator.GetAddressOf()
>
> 输出：`m_enumerator` → `IMMDeviceEnumerator*`

- **是输入和输出都放在IMMDeviceEnumerator了吗**

#### 获取默认播放设备（输出设备

```c++
hr = m_enumerator->GetDefaultAudioEndpoint(eRender,eMultimedia,m_device.GetAddressOf());
```

> `eRender`：渲染设备 = **扬声器 / 耳机（播放设备）**
>
> `eMultimedia`：多媒体音频流；
>
> **成员变量：**m_device拿到系统**默认音频输出设备（声卡）IMMDevice**。

#### 激活 **IAudioClient** 接口

```c++
hr = m_device->Activate(IID_IAudioClient,CLSCTX_ALL,NULL,
                        (void**)m_audioClient.GetAddressOf());
```

> **成员变量：**m_audioClient ： `IAudioClient` 是 WASAPI 最核心接口：管理音频流、格式、缓冲区、启停。

#### 获取系统混音格式

```c++
hr = m_audioClient->GetMixFormat(&m_mixFormat);
```

> **成员变量：**m_mixFormat 获取系统音频引擎当前使用的**共享混音格式 WAVEFORMATEX**
>
> > **共享模式**：经过 Windows 音频引擎 (Audio Engine)，多个程序共用声卡设备
> >
> > **独占模式**：绕过音频引擎，程序直接接管声卡硬件，设备归你一个程序用(这样就采集不到音频信息了)
>
> Windows 所有软件声音会被音频引擎混合成统一格式输出到声卡
>
> 这个格式包含：采样率、位深、通道数（立体声）

#### 格式调整为 **16bit** 

```c++
adjustFormatTo16Bits(m_mixFormat);
```

> 系统默认可能是 24bit/32bit float，很多编码器（aac、mp3）更兼容 16 位整型，方便后续编码存储。

```c++
int WASAPICapture::adjustFormatTo16Bits(WAVEFORMATEX *pwfx)
{
    //适配16位
    if(pwfx->wFormatTag == WAVE_FORMAT_IEEE_FLOAT){
        pwfx->wFormatTag = WAVE_FORMAT_PCM;
    }
    else if(pwfx->wFormatTag == WAVE_FORMAT_EXTENSIBLE){
        PWAVEFORMATEXTENSIBLE pEx = reinterpret_cast<PWAVEFORMATEXTENSIBLE>(pwfx);
        if(IsEqualGUID(KSDATAFORMAT_SUBTYPE_IEEE_FLOAT,pEx->SubFormat)){
            pEx->SubFormat = KSDATAFORMAT_SUBTYPE_PCM;
            pEx->Samples.wValidBitsPerSample = 16;
        }
    }
    else{
        return -1;
    }
    pwfx->wBitsPerSample = 16;
    pwfx->nBlockAlign = pwfx->nChannels * pwfx->wBitsPerSample / 8;
    pwfx->nAvgBytesPerSec = pwfx->nBlockAlign * pwfx->nSamplesPerSec;
    return 0;

}
```

> 1. **wBitsPerSample**
>
> **单个样本的比特深度（位深）**
>
> 示例：16 = 每个声道一个采样占用 16bit（2 字节）。
>
> 2. **nBlockAlign**
>
> **一个音频帧占用字节数（帧对齐）**
>
> 公式：通道数 × 每样本比特 ÷ 8
>
> > 一帧 = 同一时刻所有声道的一组采样
> >
> > 例如：2 声道、16bit
> >
> > ```
> > 2 × 16 / 8 = 4字节
> > ```
> >
> > 含义：每一组左右声道采样一共 4 字节。
>
> 3. **nSamplesPerSec**
>
> 采样率，如 48000 = 每秒 48000 组音频帧。
>
> 4. **nAvgBytesPerSec**
>
> **每秒音频总字节数（码率）**
>
> 公式：`BlockAlign × 采样率`
>
> 上面例子：4 × 48000 = 192000 Byte/s

#### 初始化音频客户端

```c++
hr = m_audioClient->Initialize(
    AUDCLNT_SHAREMODE_SHARED,
    AUDCLNT_STREAMFLAGS_LOOPBACK,
    REFTIMES_PER_SEC,
    0,
    m_mixFormat,
    NULL
);
```

> `AUDCLNT_SHAREMODE_SHARED`：共享模式（和其他应用共用音频引擎）
>
> `AUDCLNT_STREAMFLAGS_LOOPBACK`：**开启环路捕获（系统内录标志）**
>
> 没有这个 flag 就是普通播放；加上之后就可以抓取声卡输出音频。
>
> `REFTIMES_PER_SEC`：缓冲区时长（参考时间单位，100ns 为 1 单位），这里设置 1 秒缓冲区
>
> 0：周期性事件句柄（不需要事件通知填 0）
>
> m_mixFormat：音频格式
>
> NULL：会话 GUID

#### 获取缓冲区最大帧数

```c++
hr = m_audioClient->GetBufferSize(&m_bufferFrameCount);
```

> 获取m_audioClient音频环形缓冲区最多容纳多少**音频帧**，放回到`m_bufferFrameCount`。

> 一帧 = 一组采样（立体声就是左 + 右样本）
>
> 后面循环读取音频时，用来判断一次最多读取多少帧。

#### 获取WASAPI 捕获 COM 接口

```c++
hr = m_audioClient->GetService(IID_IAudioCaptureClient,
                               (void**)m_audioCaptureClient.GetAddressOf());
```

> **成员变量：**`m_audioCaptureClient` 从 IAudioClient 获取 **IAudioCaptureClient**
>
> ，负责从音频引擎缓冲区读取捕获音频数据包（PCM 原始音频、格式等）

#### 计算缓冲区时长

```c++
m_hnsActualDuration = REFERENCE_TIME(REFTIMES_PER_SEC * m_bufferFrameCount / m_mixFormat->nSamplesPerSec);
```

> `REFTIMES_PER_SEC =  10000000` ;`REFTIMES_PER_MILLISEC = 10000`
>
> **成员变量：**`m_hnsActualDuration`，代表整个缓冲区能存放多久音频。
>
> 用途：一般用于同步、超时控制、时间戳计算。

> 1. ```
>    m_bufferFrameCount / nSamplesPerSec
>    ```
>
>    含义：缓冲区全部填满，能存放多少秒的音频。
>
> 例：48000 采样率，buffer=960 帧 → 960 / 48000 = 0.02s
>
> 1. ```
>    REFTIMES_PER_SEC(10000000)
>    ```
>
>    把「秒」换算成 REFERENCE_TIME 单位（100ns 步长）
