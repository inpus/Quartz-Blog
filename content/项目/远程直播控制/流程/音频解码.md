# AAC音频解码

## 解码器初始化

### 查找解码器

```cpp
codec_ = const_cast<AVCodec*>(
    avcodec_find_decoder(codecParamer->codec_id)
);
```

> 根据音频流的 `codec_id` 查找对应的 AAC 解码器。

### 分配解码器上下文

```cpp
codecCtx_ = avcodec_alloc_context3(codec_);
```

> `AVCodecContext` 保存 AAC 解码器运行所需的配置和解码状态。

### 写入音频参数

```cpp
avcodec_parameters_to_context(codecCtx_, codecParamer);
```

> 将音频流中的编码参数复制到解码器上下文，包括：
>
> - 采样率
> - 声道数
> - 声道布局
> - 采样格式
> - 编码格式等

### 开启快速解码

```cpp
codecCtx_->flags |= AV_CODEC_FLAG2_FAST;
```

> 设置解码器快速模式，允许解码器使用部分速度优先的优化策略。

### 打开解码器

```cpp
avcodec_open2(codecCtx_, codec_, nullptr);
```

> 初始化并打开 AAC 解码器。  
> 打开成功后，解码器才可以接收 AAC 压缩数据包。

---

# 音频输出参数配置

```cpp
avContext_->audio_channels_layout = AV_CH_LAYOUT_STEREO;
avContext_->audio_fmt = AV_SAMPLE_FMT_S16;
avContext_->audio_sample_rate = 44100;
```

> 设置解码后的音频输出格式：
>
> - 声道布局：立体声
> - 声道数：2
> - 采样格式：`S16`
> - 采样率：`44100 Hz`

`AV_SAMPLE_FMT_S16` 表示：

```text
有符号16位整数采样格式
```

> 该格式通常适合直接交给音频播放设备。

---

# 初始化音频重采样器

## 获取输入声道数

```cpp
int audio_channels = codecCtx_->ch_layout.nb_channels;

if (audio_channels <= 0) {
    audio_channels = codecCtx_->channels;
}
```

> 优先从 `ch_layout.nb_channels` 获取输入声道数。

> 如果该字段无效，则使用旧版 FFmpeg 接口中的 `channels` 字段作为兼容处理。

---

## 打开重采样器

```cpp
audioResampler_->Open(
    codecCtx_->sample_rate,
    audio_channels,
    codecCtx_->sample_fmt,
    44100,
    2,
    AV_SAMPLE_FMT_S16
);
```

> 将解码器输出的音频格式转换为统一的播放格式。

输入格式：

```text
输入采样率：codecCtx_->sample_rate
输入声道数：audio_channels
输入采样格式：codecCtx_->sample_fmt
```

输出格式：

```text
输出采样率：44100 Hz
输出声道数：2
输出采样格式：AV_SAMPLE_FMT_S16
```

音频格式转换流程：

```text
AAC解码格式
    ↓
Audio_Resample
    ↓
44100Hz / 双声道 / S16
```

---

## 启动音频解码线程

```cpp
is_initial_ = true;
start();
```

> 音频解码器初始化完成后，启动 `QThread`。  
> 实际的音频解码工作在线程的 `run()` 函数中执行。

---

# AAC音频解码流程

## 准备解码对象

```cpp
int ret = -1;

AVPacketPtr packet = nullptr;
AVFramePtr outframe = nullptr;

AVFramePtr deframe = AVFramePtr(
    av_frame_alloc(),
    [](AVFrame* p) {
        av_frame_free(&p);
    }
);
```

> `packet` 用于保存待解码的 AAC 压缩数据包。

> `deframe` 用于接收 AAC 解码后的原始音频帧。

> `outframe` 用于保存重采样后的音频帧。

---

## 获取音频数据包

```cpp
while (!quit_ && audioResampler_) {
    if (!audio_queue_.size()) {
        msleep(10);
        continue;
    }

    audio_queue_.pop(packet);
}
```

> `audio_queue_` 保存待解码的 AAC 音频数据包。

> 当队列为空时，线程休眠 `10 ms`，避免循环空转占用 CPU。

> 队列中存在数据时，取出一个 `AVPacket` 进行解码。

---

## 发送音频数据包

```cpp
if (avcodec_send_packet(codecCtx_, packet.get())) {
    break;
}
```

> 将 AAC 压缩数据包发送给解码器。

数据流向：

```text
AAC AVPacket
    ↓
avcodec_send_packet()
    ↓
AAC解码器内部缓冲区
```

> `avcodec_send_packet` 只负责输入压缩数据，不直接返回解码后的音频帧。

---

## 接收解码后的音频帧

```cpp
while (1) {
    ret = avcodec_receive_frame(
        codecCtx_,
        deframe.get()
    );
}
```

> 循环调用 `avcodec_receive_frame`，获取当前数据包解码产生的所有音频帧。

数据流向：

```text
AAC压缩数据
    ↓
avcodec_send_packet()
    ↓
avcodec_receive_frame()
    ↓
解码后的AVFrame
```

---

## 处理解码状态

```cpp
if (ret == AVERROR(EAGAIN) ||
    ret == AVERROR_EOF) {
    break;
}
else if (ret < 0) {
    break;
}
```

### `AVERROR(EAGAIN)`

> 当前暂时没有可输出的音频帧，需要继续发送后续数据包。

### `AVERROR_EOF`

> 解码器已经到达输入数据末尾。

### 其他负数错误

> 表示音频解码失败，当前代码会退出本次接收循环。

### 返回值大于等于 `0`

> 表示成功接收到一帧解码后的原始音频数据。

---

# 音频重采样

## 调用重采样器

```cpp
if (audioResampler_->Convert(deframe, outframe) < 0) {
    break;
}
```

> 将解码后的音频帧转换为统一的输出格式：

```text
44100Hz
双声道
AV_SAMPLE_FMT_S16
```

---

## 重采样处理内容

音频重采样器可能完成以下操作：

```text
输入采样率转换
    ↓
输入声道转换
    ↓
输入采样格式转换
    ↓
输出音频帧
```

例如：

```text
AAC解码输出
48000Hz / 单声道 / FLTP
    ↓
重采样
    ↓
44100Hz / 双声道 / S16
```

> 具体输入格式由 AAC 音频流参数决定，输出格式由播放器要求决定。

---

# 输出音频帧

```cpp
if (outframe) {
    avContext_->audio_queue_.push(outframe);
}
```

> 将重采样后的音频帧放入公共音频帧队列，供音频播放线程读取。

完整数据流：

```text
AAC AVPacket
        ↓
audio_queue_
        ↓
avcodec_send_packet()
        ↓
avcodec_receive_frame()
        ↓
解码后的音频AVFrame
        ↓
Audio_Resample::Convert()
        ↓
44100Hz / 双声道 / S16
        ↓
avContext_->audio_queue_
        ↓
音频播放设备
```

---

# 音频解码线程退出

```cpp
void AAC_Decoder::Close()
{
    quit_ = true;

    if (isRunning()) {
        this->quit();
        this->wait();
    }
}
```

> 将 `quit_` 设置为 `true`，通知解码线程退出。

线程循环条件：

```cpp
while (!quit_ && audioResampler_) {
    // 音频解码
}
```

> 当 `quit_` 为 `true` 时，音频解码循环结束。  
> `wait()` 用于等待解码线程安全退出。

```text
初始化AAC解码器
        ↓
复制音频流参数
        ↓
打开解码器
        ↓
配置输出音频格式
        ↓
初始化音频重采样器
        ↓
启动音频解码线程
        ↓
从audio_queue_获取AAC数据包
        ↓
avcodec_send_packet()
        ↓
avcodec_receive_frame()
        ↓
获得解码后的原始音频帧
        ↓
Audio_Resample::Convert()
        ↓
转换为44100Hz / 双声道 / S16
        ↓
放入avContext_->audio_queue_
        ↓
音频渲染器播放
```
