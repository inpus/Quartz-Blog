## 视频编码

### GPU初始化

#### 找编码器

```c++
    codec_ = const_cast<AVCodec*>(avcodec_find_encoder_by_name("h264_nvenc"));

```

#### 分配编码器上下文

```c++
codecContext_ = avcodec_alloc_context3(codec_);

    codecContext_->width = config_.video.width;
    codecContext_->height = config_.video.height;
    codecContext_->time_base = {1, static_cast<int>(config_.video.framerate)};
    codecContext_->framerate = {static_cast<int>(config_.video.framerate), 1};
    codecContext_->gop_size = 30;
    codecContext_->max_b_frames = 0;
    codecContext_->pix_fmt = AV_PIX_FMT_D3D11;
    codecContext_->bit_rate = config_.video.bitrate;
    codecContext_->flags |= AV_CODEC_FLAG_GLOBAL_HEADER;
    codecContext_->rc_min_rate = config_.video.bitrate;
    codecContext_->rc_max_rate = config_.video.bitrate;
    codecContext_->rc_buffer_size = config_.video.bitrate;
```

#### 把配置参数写入编码器对应参数

```c++
av_opt_set_int(codecContext_->priv_data, "zerolatency", 1, 0);
```

> `codecContext_->priv_data`：把配置下发到编码器内部私有结构体
>
> `zerolatency,1`：开启零延迟模式

#### 分配D3D11VA 硬件上下文

```c++
    hw_device_ctx_ = av_hwdevice_ctx_alloc(AV_HWDEVICE_TYPE_D3D11VA);
```

> 支持 `AV_PIX_FMT_D3D11` 硬件帧，获取硬件上下文内部参数结构体 `AVD3D11VADeviceContext*`

> 硬件上下文都用 `AVBufferRef` 做带引用计数的封装

#### 获取硬件上下文中的结构体信息

```
    auto* hw_device_context = reinterpret_cast<AVHWDeviceContext*>(hw_device_ctx_->data);
    auto* d3d11_device_context =
        reinterpret_cast<AVD3D11VADeviceContext*>(hw_device_context->hwctx);
```

> AVBufferRef* hw_device_ctx_    
>
> ​						↓.data 
>
> ​		AVHWDeviceContext（通用外层壳，所有硬件统一结构）   
>
> ​						 ↓ .hwctx 
>
> AVD3D11VADeviceContext（D3D11VA独有的私有结构体）

#### 初始化硬件设备上下文

```c++
av_hwdevice_ctx_init(hw_device_ctx_)
```

> `hw_device_ctx_`：代表显卡硬件设备（D3D11Device），全局唯一；根据硬件设备上下文分配硬件帧池上下文

#### 分配硬件帧池上下文

```c++
hw_frames_ctx_ = av_hwframe_ctx_alloc(hw_device_ctx_);
```

> **硬件帧池上下文**，用来描述显存帧格式、分辨率、帧数量，用于分配 / 承载 `AV_PIX_FMT_D3D11` 显存 AVFrame

#### 设置硬件帧池上下文配置

```c++
    auto* frames_context = reinterpret_cast<AVHWFramesContext*>(hw_frames_ctx_->data);
    frames_context->format = AV_PIX_FMT_D3D11;
    frames_context->sw_format = AV_PIX_FMT_BGRA;
    frames_context->width = config_.video.width;
    frames_context->height = config_.video.height;
    frames_context->initial_pool_size = 4;

av_hwframe_ctx_init(hw_frames_ctx_)
```

#### 告知编码器输入帧的硬件规格

```
codecContext_->hw_frames_ctx = av_buffer_ref (hw_frames_ctx_);
```

> `av_buffer_ref`增加引用次数
>
> `codecContext_->hw_frames_ctx = ...`**告知编码器输入帧的硬件规格**。**跳过 GPU→CPU 拷贝**。

#### 打开编码器

```c++
avcodec_open2(codecContext_, codec_, nullptr)
```

### GPU编码

##### 分配帧获取对应帧的上下文

```
    AVFramePtr hw_frame(av_frame_alloc(), [](AVFrame* ptr) {
        av_frame_free(&ptr);
    });
    hw_frame->format = AV_PIX_FMT_D3D11;
    hw_frame->hw_frames_ctx = av_buffer_ref(hw_frames_ctx_);
```

> `hw_frames_ctx = av_buffer_ref(hw_frames_ctx_)`：
>
> 把硬件帧上下文绑定到这一帧，告诉 FFmpeg：这张帧属于哪一套显存帧池（分辨率、格式、D3D 设备）。
>
> `av_buffer_ref` 增加引用计数，保证 hw_frames_ctx 不会提前销毁。

##### 申请显存获取帧数据

```
av_hwframe_get_buffer(hw_frames_ctx_, hw_frame.get(), 0)
```

> 执行之后：
>
> - `hw_frame->data[0]` 内部会存放 FFmpeg 管理的 D3D11 纹理；
> - `hw_frame` 具备完整硬件缓冲区，可以直接送入 `avcodec_send_frame` 硬件编码。

##### GPU拷贝

```
d3d_context_->CopySubresourceRegion(
    destination,
    static_cast<UINT>(frameDesc->index), // 目标子资源索引
    0, 0, 0,                             // dest左上角偏移 x,y,z
    frame.texture,                       // 源纹理：WGC捕获的画面
    0,                                   // 源子资源索引（WGC单纹理固定0）
    &source_box                          // 源区域裁剪框（宽高、偏移）
);
```

>  把 WGC 捕获纹理的数据复制到 FFmpeg 帧池预先创建好的 D3D11 纹理里，之后将 FFmpeg 托管的这张纹理对应的 AVFrame 送入编码器。
>
> 主要让ffmpeg管理

#####  PTS 时间戳换算

```c++
hw_frame->pts = av_rescale_q(frame.pts_us,
                             AVRational{1, 1000000},
                             codecContext_->time_base);
```

> `frame.pts_us`：WGC 给出的时间戳，单位**微秒（1/1000000 s）**
>
> `av_rescale_q`：时间基转换
>
> 输入时间基：`1/1000000`
>
> 输出时间基：编码器 `time_base`（例如 h264_nvenc 常用 `1/60`、`1/1000`）
>
> 作用：给 AVFrame 打上**合法 PTS**，保证输出视频时序正确，音画同步依赖这个时间戳。

##### 强制i帧，发送frame

```c++
const bool key_frame = frame_count_ % gop_frames_ == 0;
hw_frame->pict_type = key_frame ? AV_PICTURE_TYPE_I : AV_PICTURE_TYPE_NONE;
if (key_frame)
{
    av_opt_set_int(codecContext_->priv_data, "forced_idr", 1, 0);
}

avcodec_send_frame(codecContext_, hw_frame.get())
if (key_frame)
{
    av_opt_set_int(codecContext_->priv_data, "forced_idr", 0, 0);
}
```

> `gop_frames_`：GOP 长度，比如每 60 帧强制出一个关键帧；
>
> `AV_PICTURE_TYPE_I`：提示编码器希望输出 I 帧；
>
> `AV_PICTURE_TYPE_NONE`：交由编码器自主选择（P/B 帧）。

> 轮到关键帧 → 开启 `forced_idr=1`
>
> send_frame 送入当前帧
>
> 立刻关闭 `forced_idr=0`，防止后续普通帧被误强制为 IDR

> 最后发送帧，以及编码参数上下文

##### 获取packet

```c++
avcodec_receive_packet(codecContext_, packet.get())
```
