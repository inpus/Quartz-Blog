# 音频渲染

## 初始化音频格式

```cpp
audioFmt_.setSampleRate(44100);
audioFmt_.setChannelCount(2);
audioFmt_.setSampleFormat(QAudioFormat::Int16);
```

> 设置默认音频格式：
>
> - 采样率：`44100 Hz`
> - 声道数：双声道
> - 采样格式：`16位有符号整数`

---

## 初始化音频输出

```cpp
bool AudioRender::InitAudio(
    int nChannels,
    int SampletRate,
    int nSampleSize
)
```

> 根据解码器输出的音频参数初始化 Qt 音频播放设备。

### 检查初始化状态

```cpp
if (audioOut_ || is_initail_ || device_)
    return true;
```

> 如果音频输出设备已经初始化，则不重复创建。

### 检查输入参数

```cpp
if (nChannels <= 0 || SampletRate <= 0)
    return false;
```

> 声道数和采样率必须是有效值。

---

# 配置音频格式

## 设置声道数和采样率

```cpp
audioFmt_.setChannelCount(nChannels);
audioFmt_.setSampleRate(SampletRate);
```

> 使用传入的参数配置音频输出格式。

例如：

```text
声道数：2
采样率：44100 Hz 或 48000 Hz
```

---

## 设置采样格式

```cpp
QAudioFormat::SampleFormat sampleFormat =
    QAudioFormat::Int16;

if (nSampleSize == 8 || nSampleSize == 1)
    sampleFormat = QAudioFormat::UInt8;
else if (nSampleSize == 16 || nSampleSize == 2)
    sampleFormat = QAudioFormat::Int16;
else if (nSampleSize == 32 || nSampleSize == 4)
    sampleFormat = QAudioFormat::Int32;

audioFmt_.setSampleFormat(sampleFormat);
```

> 根据每个采样点的字节数或位数选择 Qt 音频采样格式。

对应关系：

| 输入参数    | Qt采样格式 |
| ----------- | ---------- |
| `8` 或 `1`  | `UInt8`    |
| `16` 或 `2` | `Int16`    |
| `32` 或 `4` | `Int32`    |

当前 AAC 解码和重采样流程输出的是：

```text
AV_SAMPLE_FMT_S16
```

因此对应 Qt 格式：

```text
QAudioFormat::Int16
```

---

## 检查音频格式

```cpp
if (!audioFmt_.isValid())
    return false;
```

> 检查当前系统是否支持配置的音频格式。

---

# 创建音频输出设备

## 创建 `QAudioSink`

```cpp
audioOut_ = new QAudioSink(audioFmt_);
```

> `QAudioSink` 是 Qt 提供的音频输出对象，用于将 PCM 音频数据发送到系统播放设备。

---

## 设置缓冲区大小

```cpp
audioOut_->setBufferSize(409600);
```

> 设置音频输出缓冲区大小为 `409600` 字节。

缓冲区的作用：

```text
音频帧
    ↓
QAudioSink内部缓冲区
    ↓
声卡设备
```

> 缓冲区过小可能导致声音断续，过大则可能增加播放延迟。

---

## 设置音量

```cpp
audioOut_->setVolume(volume_ / 100.0);
```

> `QAudioSink::setVolume` 的音量范围通常为 `0.0` 到 `1.0`。

例如：

```text
volume_ = 100  →  音量 1.0
volume_ = 50   →  音量 0.5
volume_ = 0    →  静音
```

---

## 启动音频设备

```cpp
device_ = audioOut_->start();
```

> 启动音频输出设备，并获取用于写入 PCM 数据的 `QIODevice`。

数据写入流程：

```text
QAudioSink::start()
        ↓
获取QIODevice
        ↓
device_->write()
        ↓
系统音频设备
```

### 检查设备是否启动成功

```cpp
if (!device_) {
    delete audioOut_;
    audioOut_ = nullptr;
    return false;
}
```

> 如果无法获取音频设备，则释放已经创建的 `QAudioSink`。

---

## 设置音频周期大小

```cpp
periodSize_ = audioFmt_.bytesForFrames(1024);
```

> 计算 `1024` 个音频采样帧所占用的字节数。

计算公式：

```text
字节数 =
采样帧数量 × 声道数 × 每个采样点的字节数
```

例如：

```text
1024 × 2 × 2 = 4096 字节
```

---

## 完成初始化

```cpp
is_initail_ = true;
return true;
```

> 音频格式、音频输出设备和播放设备初始化完成。

---

# 获取可写入空间

```cpp
int AudioRender::AvailableBytes()
{
    if (!audioOut_)
        return -1;

    qint64 avail = audioOut_->bytesFree() - periodSize_;
    return avail > 0 ? static_cast<int>(avail) : 0;
}
```

> 获取音频输出缓冲区中可以写入的空间。

### 获取剩余空间

```cpp
audioOut_->bytesFree();
```

> 返回 `QAudioSink` 内部缓冲区当前剩余的可写字节数。

### 预留一个周期

```cpp
qint64 avail = audioOut_->bytesFree() - periodSize_;
```

> 减去一个音频周期大小，避免缓冲区接近满载时继续写入过多数据。

返回值含义：

```text
-1       音频输出设备不存在
0        当前没有足够的可写空间
大于0    当前可以写入的字节数
```

---

# 写入音频数据

## 写入函数

```cpp
void AudioRender::Write(AVFramePtr frame)
```

> 将解码和重采样后的音频帧写入 Qt 音频设备。

---

## 检查音频帧

```cpp
if (!device_ ||
    !audioOut_ ||
    !frame ||
    !frame->data[0] ||
    frame->nb_samples <= 0)
{
    return;
}
```

> 以下情况不会执行写入：
>
> - 音频设备没有启动
> - `QAudioSink` 不存在
> - 音频帧为空
> - 音频帧没有数据
> - 音频帧采样数小于等于 `0`

---

## 检查采样格式

```cpp
if (frame->format != AV_SAMPLE_FMT_S16 &&
    frame->format != AV_SAMPLE_FMT_NONE)
{
    return;
}
```

> 当前音频渲染器要求输入为 packed S16 格式。

对应关系：

```text
FFmpeg：AV_SAMPLE_FMT_S16
Qt：    QAudioFormat::Int16
```

> `AV_SAMPLE_FMT_S16` 表示交错排列的 16 位有符号 PCM 数据。

双声道数据排列示例：

```text
L0 R0 L1 R1 L2 R2 ...
```

> 如果输入是 `AV_SAMPLE_FMT_S16P`，则属于平面格式，左右声道数据分别位于不同的数据平面，不能直接按照当前方式写入。

---

# 获取音频参数

## 获取声道数

```cpp
int channels =
    static_cast<int>(frame->ch_layout.nb_channels);

if (channels <= 0)
    channels = frame->channels;
```

> 优先从新版本 FFmpeg 的 `ch_layout.nb_channels` 获取声道数。

> 如果获取失败，则使用兼容字段 `frame->channels`。

---

## 获取每个采样点的字节数

```cpp
int bytesPerSample =
    av_get_bytes_per_sample(
        static_cast<AVSampleFormat>(frame->format)
    );
```

> 根据音频采样格式获取每个采样点占用的字节数。

例如：

```text
UInt8：  1字节
S16：    2字节
S32：    4字节
```

如果无法获取，则使用输出音频格式中的采样大小：

```cpp
if (bytesPerSample <= 0)
    bytesPerSample = audioFmt_.bytesPerSample();
```

---

## 检查音频参数

```cpp
if (channels <= 0 || bytesPerSample <= 0)
    return;
```

> 声道数和采样点字节数必须有效，否则无法正确计算音频数据长度。

---

# 计算音频数据大小

```cpp
const qsizetype byteCount =
    static_cast<qsizetype>(frame->nb_samples) *
    channels *
    bytesPerSample;
```

计算公式：

```text
音频数据大小 =
采样数量 × 声道数 × 每个采样点字节数
```

例如：

```text
1024个采样
2个声道
每个采样点2字节

1024 × 2 × 2 = 4096字节
```

---

# 创建PCM数据

```cpp
QByteArray pcmData(
    reinterpret_cast<const char*>(frame->data[0]),
    byteCount
);
```

> 将 `AVFrame` 中的音频数据包装为 `QByteArray`。

由于当前输出格式是 packed S16：

```text
frame->data[0]
    ↓
连续PCM数据
    ↓
QByteArray
```

---

# 写入音频设备

```cpp
device_->write(pcmData);
```

> 将 PCM 数据写入 `QAudioSink` 对应的 `QIODevice`。

完整数据流：

```text
AVFrame
    ↓
frame->data[0]
    ↓
QByteArray
    ↓
QIODevice::write()
    ↓
QAudioSink缓冲区
    ↓
系统声卡
    ↓
扬声器
```

---

# 暂停音频播放

```cpp
void AudioRender::Pause()
{
    if (audioOut_)
        audioOut_->suspend();
}
```

> 暂停向音频设备播放数据，但保留当前播放状态和缓冲区内容。

---

# 恢复音频播放

```cpp
void AudioRender::Resume()
{
    if (audioOut_)
        audioOut_->resume();
}
```

> 恢复音频播放，继续处理音频缓冲区中的数据。

---

# 停止音频播放

```cpp
void AudioRender::Stop()
{
    if (audioOut_) {
        audioOut_->stop();
        delete audioOut_;
        audioOut_ = nullptr;
    }

    device_ = nullptr;
    is_initail_ = false;
}
```

> 停止音频输出并释放 `QAudioSink`。

释放流程：

```text
停止QAudioSink
        ↓
释放audioOut_
        ↓
清空device_
        ↓
重置初始化状态
```

---

# 音频渲染总流程

```text
获取解码后的音频AVFrame
        ↓
确认音频格式为S16
        ↓
获取声道数和采样点字节数
        ↓
计算PCM数据大小
        ↓
读取frame->data[0]
        ↓
封装为QByteArray
        ↓
写入QAudioSink对应的QIODevice
        ↓
QAudioSink内部缓冲
        ↓
系统音频设备
        ↓
扬声器播放
```

> 注意：AAC 解码流程中配置的输出采样率为 `44100 Hz`，而 `AudioRender` 构造函数中的默认采样率为 `48000 Hz`。实际播放格式由 `InitAudio` 传入的 `SampletRate` 决定，解码器和渲染器必须使用一致的采样率。
