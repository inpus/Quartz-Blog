## 音频编码

### 初始化

#### 找编码器

```c++
    codec_ = const_cast<AVCodec*>(avcodec_find_encoder(AV_CODEC_ID_AAC));
```

> 设置了aac的编码器

#### 创建对应编码器的上下文并设置

```
codecContext_ = avcodec_alloc_context3(codec_);
    codecContext_->sample_rate = config_.audio.samplerate;
    codecContext_->sample_fmt = AV_SAMPLE_FMT_FLTP;
    av_channel_layout_default(&codecContext_->ch_layout, config_.audio.channels);
    codecContext_->bit_rate = config.audio.bitrate;
    codecContext_->time_base = {1, codecContext_->sample_rate};
    //获取全局的aac头部
    codecContext_->flags |= AV_CODEC_FLAG_GLOBAL_HEADER;
```

> ### 1. AV_SAMPLE_FMT_S16（16-bit signed integer，交错）
>
> FFmpeg 中 `S16` / `S32` / `FLT` 默认都是**交错布局**，也就是一个采样点中的各声道数据连续存放。
>
> 内存排列方式：
>
> ```
> L0 R0 L1 R1 L2 R2 ...
> ```
>
> 所有声道数据都挤在同一块缓冲区里，通常只有 `data[0]` 有效：
>
> ```c
> frame->data[1] = NULL;
> ```
>
> 也就是说，这是一个“单缓冲区 + 交错存储”的布局。
>
> ### 2. AV_SAMPLE_FMT_FLT（32-bit float，交错）
>
> 与 `S16` 相同，仍然是交错布局：
>
> ```
> L0 R0 L1 R1 L2 R2 ...
> ```
>
> 也只有 `data[0]` 有效，所有声道仍然连续存放在一块内存中。
>
> ### 3. AV_SAMPLE_FMT_FLTP（32-bit float，平面 Planar）
>
> 这是平面格式，每个声道各自占一块独立缓冲区：
>
> - `data[0]`：`L0 L1 L2 ...`（左声道）
> - `data[1]`：`R0 R1 R2 ...`（右声道）
>
> 对于更多声道，通常依次存放到 `data[2]`、`data[3]` 等。
>
> 这类格式常见于重采样输出，也更适合编码器的输入要求。
>
> ### sample_rate（采样率）
>
> 采样率表示每秒钟采样多少个音频样本，常见值为 `48000`、`44100` Hz。
>
> ### bit_rate（目标码率）
>
> 表示目标音频编码后的码率，单位是 **bps**（bits per second）。
>
> ### time_base（时间基）
>
> 对于音频，时间基通常为：`1 / sample_rate`。
>
> 这表示每个采样点对应的时间刻度大小。
>
> PTS 计算公式：
>
> ```
> pts = sample_count × time_base
> ```
>
> 即：`样本数量 × 时间基`。后续为 `AVFrame` 设置 `pts` 时，必须与这套时间基保持一致。
>
> ### AV_CODEC_FLAG_GLOBAL_HEADER
>
> 该标志用于把 AAC 等格式的特定头信息（例如 ESDS）从每个 `AVPacket` 中剥离出来，放到 `codecContext_->extradata` 中，而不是重复写入每一帧数据。
>
> | 格式 | 类型 | 布局 | 声道存储 | 典型来源 | AAC 编码器是否支持直接输入 |
> | --- | --- | --- | --- | --- | --- |
> | `AV_SAMPLE_FMT_S16` | 16-bit int | 交错 | 全部数据存放在 `data[0]` | 声卡采集（WASAPI） | ❌ 不支持 |
> | `AV_SAMPLE_FMT_FLT` | 32-bit float | 交错 | 全部数据存放在 `data[0]` | 部分音频库 | ❌ 不支持 |
> | `AV_SAMPLE_FMT_FLTP` | 32-bit float | 平面 | 每个声道独立存放在 `data[]` | 重采样输出 | ✅ 唯一支持 |

### 重采样

#### 设置参数、获取内存

```c++
    out_frame.reset(av_frame_alloc(),[](AVFrame* ptr){av_frame_free(&ptr);});
    out_frame->sample_rate = out_samplerate_;
    out_frame->format = out_format_;

    av_channel_layout_default(&out_frame->ch_layout, out_channels_);
    int64_t delay = swr_get_delay(swr_context_,in_frame->sample_rate);
    out_frame->nb_samples = av_rescale_rnd(delay + in_frame->nb_samples, out_samplerate_,
                                           in_frame->sample_rate, AV_ROUND_UP);
    out_frame->pts = out_frame->pkt_dts = in_frame->pts;

    //获取内存
    if(av_frame_get_buffer(out_frame.get(),0) != 0){
        return -1;
    }
```

- **sample_rate**：设置重采样后的**目标采样率**（例如 44100Hz 或 48000Hz）。

- **format**：设置重采样后的**目标采样格式**（例如 AV_SAMPLE_FMT_S16 16位整型，或 AV_SAMPLE_FMT_FLTP 单精度浮点平面格式）。

- **av_channel_layout_default**：根据目标声道数（如 2），设置默认的声道布局（如双声道立体声 Stereo）。*(注：这是 FFmpeg 5.0+ 推荐的新 API)*。

- 音频重采样内部有滤波器缓存，通常会产生延迟（部分数据可能还残留在 swr_context_ 中）。

- **swr_get_delay(...)**：获取重采样器中当前残留的延迟样本数。

- **av_rescale_rnd(...)**：根据输入样本数、延迟量以及输入/输出采样率的比例，换算出**输出帧至少需要容纳多少个样本（nb_samples）**。

  ```
  输出样本数=(延迟+输入样本数)×输入采样率/输出采样率
  ```

- **AV_ROUND_UP**：向上取整，宁可多分一点空间，防止重采样时内存越界溢出。

### 编码

#### 获取重采样的音频缓冲区

```c++
    for(int ch = 0; ch < channels; ++ch){
        const float* src = reinterpret_cast<const float*>(out_frame->data[ch]);
        auto& buf = resample_buffer_[ch];
        buf.insert(buf.end(), src, src + out_frame->nb_samples);
    }
```

> 左右两声道平面获取

> `buf.insert(buf.end(), src, src + out_frame->nb_samples);`
>
> **把当前声道 `src` 指向的全部浮点样本，追加到 `resample_buffer_[ch]` 容器尾部**，实现音频数据持续累积。

#### 编码

```c++
    while(!resample_buffer_.empty() &&
          static_cast<int>(resample_buffer_[0].size()) >= frame_samples){
        AVFramePtr send_frame(av_frame_alloc(),[](AVFrame* ptr){av_frame_free(&ptr);});
        send_frame->format = AV_SAMPLE_FMT_FLTP;
        send_frame->sample_rate = codecContext_->sample_rate;
        av_channel_layout_copy(&send_frame->ch_layout, &codecContext_->ch_layout);
        send_frame->nb_samples = frame_samples;
        send_frame->pts = out_pts_samples_;

        if(av_frame_get_buffer(send_frame.get(),0) < 0){
            return nullptr;
        }

        for(int ch = 0; ch < channels; ++ch){
            float* dst = reinterpret_cast<float*>(send_frame->data[ch]);
            auto& buf = resample_buffer_[ch];
            memcpy(dst, buf.data(), frame_samples * sizeof(float));
            buf.erase(buf.begin(), buf.begin() + frame_samples);
        }

        out_pts_samples_ += frame_samples;

        int ret = avcodec_send_frame(codecContext_, send_frame.get());
        if(ret != 0){
            return nullptr;
        }

        AVPacketPtr pkt(av_packet_alloc(),[](AVPacket* ptr){av_packet_free(&ptr);});
        ret = avcodec_receive_packet(codecContext_, pkt.get());
        if(ret == 0){
            av_packet = pkt;
            break;
        }
        if(ret == AVERROR(EAGAIN)){
            continue;
        }
        return nullptr;
    }
```

> 1. 设置send_frame配置参数，获取缓冲区
> 2. 获取左右声道的数据，然后删除对应缓冲区长度
> 3. 将获取的数据`avcodec_send_frame`发送
> 4. 最后接受`avcodec_receive_packet`
